# Crypto Pilot — Personal AI Crypto Trading Assistant

V1 is a paper-first market intelligence app. It reads public Binance market data and calculates deterministic technical signals before any AI explanation is added.

## Current V1
- Binance public 1H market data
- BTC, ETH, BNB, SOL, XRP, ADA, DOGE scanner
- EMA 20/50/200
- RSI 14
- ATR-based risk reference
- Support/resistance
- Rule-based setup score
- Risk/reward reference
- Paper-only architecture
- Mobile-first dashboard

## Planned next
1. Paper trade journal and simulated portfolio
2. Multi-timeframe analysis (15m/1h/4h/1d)
3. Backtesting engine
4. AI analyst using Vercel AI Gateway only when requested
5. Alerts
6. Optional exchange connection much later, with trading disabled by default

## Safety
This is an analysis/learning tool, not a profit guarantee. Real-money trading is intentionally excluded from V1.
